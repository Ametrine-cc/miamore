### Examples

If you want to check out the original <ToolTip function="C">`C`</ToolTip> example that was made alongside development of miamore run the following commands to compile.

```bash
make static example
```

To have a luck at the example written in rust run these commands to compile it.

```bash
# build library
make static rust-build

# build build and run example
make rust-test
```
